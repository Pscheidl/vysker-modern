# Seasonal chapel illustration

The homepage displays the spring, summer, autumn or winter version according to
meteorological seasons in the Europe/Prague time zone. From the first Sunday of
Advent through 31 December, the Christmas version takes precedence. The first
Sunday of Advent is calculated each year. Visitors who keep the page open across
midnight see the new season without reloading.

Autumn has falling leaves and winter and Christmas have snow. These decorative
effects are hidden when the visitor prefers reduced motion. If JavaScript is
disabled, the original summer illustration remains visible. The same images
have light and dark variants and the browser displays the version corresponding
to the current site theme.

The original summer illustration is reused. The other eight seasonal image
variants were generated from the chapel illustration with the built-in image
generator. They are visual interpretations, not photographs of the decorations.
